When starting an ASR project for a low-resource language, it is difficult to know whether a small dataset and modest hardware are enough to produce a working end-to-end pipeline before investing significant time in data collection and model development. This repository provides a minimal, reproducible pipeline that executes ingest → preprocess → finetune → evaluate → quantize → serve on a small (~1 hour) subset of the FLEURS Yoruba dataset using Whisper Tiny, completing on a CPU-only machine in under [x] minutes. The objective is not to achieve a low Word Error Rate (WER), but to demonstrate that the complete training and deployment loop closes successfully from raw data to a served model.
